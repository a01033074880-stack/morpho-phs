# Morphohedra / NR-PHMS — 理论 v1（Phase 1 定稿）

> 本文件取代 `theory_corrected.md`（Phase 0）作为项目的理论基准。完整证明的 LaTeX 版见 `theory_proofs.tex` / `theory_proofs.pdf`。

**论文主贡献（按用户决策排序）**
1. 拓扑晶格：2 自由度陀螺蜂窝晶格，Chern 数非零的带隙落在可听频段，时域单向边缘传输、缺陷绕行；
2. 无条件稳定（对非线性/回旋/阻尼/增益门控而言）的显式格式 ESAV-LF：离散功率平衡为恒等式；
3. 无源（能量不增）参数调制 ENPU；
4. 形态发生降级为控制层：Barkley 可激介质（螺旋波），通过“能量防火墙”耦合，可证明不破坏声学层的无源性。

**诚实说明：“无条件稳定”的确切含义。** ESAV-LF 的稳定性与非线性刚度（α、β 任意大）、回旋强度 g、非线性阻尼 η、振幅大小均无关；但作为显式格式，它仍需要**线性** CFL 条件 γ = h·ω_max/2 < 1（ω_max² = λ_max(M⁻¹K)）。在音频参数下 γ ≈ 0.20（m=1）或 0.29（m_min=0.5），离 1 很远。论文中应写作“unconditionally stable with respect to the nonlinearity, gyroscopy and gated gain; linear CFL only”。

## 1. 定义

**定义 1（晶格与状态）.** 平行四边形蜂窝薄片，Lx×Ly 个元胞，每元胞 2 个格点（A/B 子格），格点数 N = 2LxLy，最近邻键集合 𝔅。每个格点 i 有平面位移 x_i ∈ ℝ²，全体自由度 q ∈ ℝ^{2N}（交错排列 (x₀,y₀,x₁,y₁,…)）。

**定义 2（2-DOF 陀螺蜂窝端口哈密顿系统）.**
- 质量 M = diag(m_i I₂)，m_i > 0；
- 刚度 K = k₀ I + Σ_{(i,j)∈𝔅} k_c (e_i − e_j)(e_i − e_j)ᵀ ⊗ n_{ij} n_{ijᵀ}（中心力弹簧，n_{ij} 为键单位向量），K ⪰ 0；
- 局部势 U(q) = Σ_k U_k(q_k)，U_k(s) = α/4·s⁴ + β·log cosh s，α, β ≥ 0 ⇒ U_k 凸、U_k(0)=0、U_k ≥ 0；
- 回旋 G = blockdiag(g_i J₂)，J₂ = [[0,1],[−1,0]]（反对称，不做功）；
- Rayleigh 项 D(v) = blockdiag((−μ_i + η_i|v_i|²) I₂)，η_i ≥ 0；μ_i ≤ 0 为耗散，μ_i > 0 为负阻（自激）；
- 端口 B = [b₁,…,b_P]，b_k = e_{s_k} ⊗ (b_x,b_y)（每个 MPE 音符一个注入/拾取格点）。

连续方程：M q̈ = −Kq − ∇U(q) + G q̇ − D(q̇) q̇ + B u，y = Bᵀ q̇；
哈密顿量 H = ½ q̇ᵀMq̇ + ½ qᵀKq + U(q)，功率平衡 dH/dt = yᵀu − q̇ᵀD(q̇)q̇。

**定义 3（ESAV-LF 格式）.** 步长 h = 1/f_s，记 w = q^{n+1} − q^{n−1}，v̄ = w/(2h)，v^{n−1/2} = (q^n − q^{n−1})/h，标量辅助变量 ψ ∈ ℝ^{2N}（逐自由度），c₀ > 0：

  M (q^{n+1} − 2q^n + q^{n−1})/h² = −K q^n − g^n ⊙ (ψ^{n+1} + ψ^{n−1})/2 + (G − D^n) v̄ + B u^n,
  ψ^{n+1} = ψ^{n−1} + g^n ⊙ w,  g^n = U′(q^n) / √(2U(q^n) + c₀)，D^n = D(v^{n−1/2})（滞后速度）。

由于 G 与 D^n 都是格点内 2×2 块，未知量 w 的线性系统按格点解耦：
  [[a_x, −c],[c, a_y]] w_i = r_i，a_• = m_i/h² + ½g_•² + d_i/(2h)，c = g_i/(2h)，
  w_x = (a_y r_x + c r_y)/det，w_y = (a_x r_y − c r_x)/det，det = a_x a_y + c² > 0。
⇒ **完全显式**，每格点一次除法，无迭代。可解条件：a_• > 0，即 μ_i < 2m_i/h（音频参数下 μ < 48 000 s⁻¹，远大于实际使用的 ≤ 2 000）。

**定义 4（离散能量）.**
  E^{n−1/2} = ½ (v^{n−1/2})ᵀ M v^{n−1/2} + ½ (q^n)ᵀ K q^{n−1} + ¼ Σ_k (ψ_k^n² + ψ_k^{n−1}²) − N_dof c₀/2，
  Ẽ := E + N_dof c₀/2（平移能量，Ẽ ≥ 0，见定理 2）。

## 2. 定理

**定理 1（离散功率平衡，恒等式）.** 对任意参数、任意状态、任意输入：
  E^{n+1/2} − E^{n−1/2} = h (u^n)ᵀ y^n − h v̄ᵀ D^n v̄，y^n := Bᵀ v̄。

*证明要点.* 用 w = 2h v̄ 左乘格式：质量项给出 ‖v^{n+1/2}‖²_M − ‖v^{n−1/2}‖²_M；K 对称给出 −(q^{n+1}ᵀKq^n − q^nᵀKq^{n−1})；SAV 项由 ψ 更新得 −½(‖ψ^{n+1}‖² − ‖ψ^{n−1}‖²)；回旋项 2h v̄ᵀG v̄ = 0；两边除以 2 即得。∎（完整推导见 tex。）

*机器验证（p1_a_verify.json）：* sympy 对 1 格点（18 项）与 2 格点（44 项，符号对称 K）展开后恒等式成立；mpmath 50 位精度下单格点、2×2、3×3 薄片的最大相对残差为 1.0e-50、5.9e-51、5.0e-51（μ<0 与 μ>0 均测）。C++ 双精度：8×8、4000 步、随机有源参数，最大相对残差 5.5e-16（T2），四次势快速路径 6.5e-16（T2c）。

**定理 2（能量下界与无源性）.** 若 CFL 条件 M − (h²/4)K ≻ 0（等价于 γ := h ω_max/2 < 1），则
  Ẽ^{n−1/2} ≥ ½(1−γ²)‖v^{n−1/2}‖²_M + ½ q̄ᵀKq̄ + ¼Σ(ψ²+ψ²) ≥ 0，q̄ = (q^n+q^{n−1})/2。
若再有 μ_i ≤ 0（∀i），则 D^n ⪰ 0，Ẽ^{n+1/2} − Ẽ^{n−1/2} ≤ h (u^n)ᵀ y^n（离散无源性），且 u ≡ 0 时 Ẽ 单调不增；k₀ > 0 时 q̄ 与 v 有界，从而 q 有界——与 α、β、g、η 的大小及初始振幅无关。

*证明要点.* 恒等式 q^nᵀKq^{n−1} = q̄ᵀKq̄ − (h²/4) vᵀKv，再用 vᵀ(M − h²K/4)v ≥ (1−γ²)‖v‖²_M。∎

*机器验证（p1_c_gate_passive_L8.json，p1_c_gate_modul_L8.json）：* 8×8（256 自由度），各 10 000 组极端冲击（初速 10¹–10⁶、位移 10⁻¹–10²、4 个 10⁴–10⁹ 力脉冲），2048 步：0 个非有限值；逐步无源性超额（ΔE − h·uᵀy）/尺度 的最大值为 −3.0e-7（被动）与 −5.0e-8（调制），累计无源性超额最大 −1.0e-6 与 −1.1e-6（均 < 0，即没有任何一步违背）。

**定理 3（ENPU：能量不增参数更新）.** 设当前参数 P 与新参数 P′ 都可容许（α′,β′ ≥ 0，P′ 满足 CFL）。令 q̄ = (q^n+q^{n−1})/2，v = (q^n−q^{n−1})/h，v′_i = √(m_i/m′_i)·v_i，候选状态 Z(s) = (s(q̄ + h v′/2), s(q̄ − h v′/2))，ψ 重新投影为 √(2U′(·)+c₀)。则 F(s) := E′(Z(s)) 满足 F(s) ≤ s·F(1)（s ∈ [0,1]）。取 s = 1（若 F(1) ≤ max(E_old,0)），否则 s = max(E_old,0)/F(1)，得 E_new ≤ max(E_old, 0)。

*证明要点.* 重投影后 E′(Z(s)) = s²A + ½Σ[U′_k(s a_k) + U′_k(s b_k)]，其中 A = ½v′ᵀ(M′ − h²K/4)v′ + ½q̄ᵀKq̄ ≥ 0（CFL）；凸且 U(0)=0 ⇒ U(sa) ≤ sU(a)；故 F(s) ≤ s²A + sB ≤ s(A+B) = sF(1)。∎

*机器验证：* 10 000 组 ×32 次随机参数跳变（m ∈ [0.5,2]、α、β、g 换号、μ），共 320 000 次 ENPU：最大相对能量增量 −3.5e-8（被动调制）/ −5.1e-8（有源），即没有一次增加能量；其中 27.8% / 27.5% 的跳变需要缩放（s<1）。C++ T3：2000 次随机跳变最大 −4.3e-7。

*说明.* 质量变化以“保持动能”的方式（v′ = √(m/m′)v）施加；刚度增大会在固定位移下增加势能，因此 ENPU 必须缩放（这是物理的：硬化需要外界做功，而无源调制不允许做功）。可选变体 ENPU-ψ（不重投影 ψ，能量严格守恒、无缩放，但 SAV 一致性误差冻结）列入 Phase 2 听感对比。

**定理 4（能量门控增益：自激有界）.** 设 μ_i ≤ μ_max（可正），η_i ≥ 0，门控 μ_eff = μ（若 E^{n−1/2} < E_cap），否则 min(μ, 0)。令 m_min、γ 同上，δ = hμ_max/(m_min(1−γ²)) < 1，ρ = (1+δ)/(1−δ)。则当 u ≡ 0 时，对所有 n：
  Ẽ^{n+1/2} ≤ max(Ẽ^{1/2}, ρ·Ẽ_cap)，Ẽ_cap = E_cap + N_dof c₀/2，
并且 ENPU 调制（每 64 样本）不改变该界。

*证明要点.* 门打开时 −v̄ᵀD v̄ ≤ μ_max‖v̄‖² ≤ (μ_max/m_min)·½(‖v^{n+1/2}‖²_M + ‖v^{n−1/2}‖²_M) ≤ δ(Ẽ^{n+1/2} + Ẽ^{n−1/2})/h，代入定理 1 得 Ẽ⁺ ≤ ρẼ⁻ < ρẼ_cap；门关闭时 Ẽ⁺ ≤ Ẽ⁻。归纳即得。∎

*机器验证：* 10 000 组（μ ∈ [0,60]、η>0、E_cap = 1e9、随机调制）最大 Ẽ/界 = 1.0000（初始能量主导）；为了真正压测门控，另跑 10 000 组 “activecap”（μ ∈ [0,2000]、E_cap = 1e5、小初值，能量必须从小值增长到门限）：0 个非有限值，100% 的试验能量至少达到 E_cap/2，max Ẽ/界 = 0.915（ρ = 1.1945），max E/E₀ = 820（p1_c_gate_activecap_L8.json）。C++ T4：4 s 螺旋调制自激，max Ẽ = 1.00586e7 ≤ ρẼ_cap = 1.01338e7（ρ = 1.01337）。

**命题 5（多端口 / MPE）.** 对 P 个共位端口（每个音符一个注入点 b_k 与拾取 y_k = b_kᵀ v̄），定理 1 变为
  Ẽ^{n+1/2} − Ẽ^{n−1/2} = h Σ_k u_k^n y_k^n − h v̄ᵀD v̄。
因此（i）每个音符的输入功率 u_k y_k 可单独计量；（ii）任一端口接无源终端（u_k = −r_k y_k，r_k ≥ 0，例如“手指阻尼”）只会减少能量；（iii）与任何无源外部系统做功率保持互联后整体仍无源。所有音符共享同一晶格（耦合来自晶格本身），这正是“一个晶格、多个激励点”的物理含义。

**命题 6（能量防火墙：控制层耦合不破坏无源性）.** 设控制层状态 z（Barkley 介质，任意维、任意动力学，包括由音频特征驱动的单向触发以及由声学输出反馈的闭环）在控制节拍 t_j 处产生参数 P_j = Φ(z_j)，Φ 取值于可容许集 𝒜 = {m ∈ [m_lo, m_hi]，α,β ≥ 0，μ ≤ μ_max，η ≥ 0，g ∈ ℝ}（由钳位实现）。参数只在节拍处经 ENPU 生效。则：
- 若 μ_max ≤ 0：对任意 z 的轨迹，Ẽ^n ≤ Ẽ^0 + Σ_{m<n} h u^mᵀy^m（无源）；
- 若 μ_max > 0 且启用门控：u ≡ 0 时 Ẽ^n ≤ max(Ẽ^0, ρẼ_cap)。
*证明.* 节拍之间参数固定，适用定理 1/2/4；节拍处 ENPU 使 E 不增（定理 3）。注入声学层的能量只有两条通道：端口功率 uᵀy 与门控增益 μ>0；Φ 的输出只能改变参数而不能直接注入能量。因此不论控制律如何（单向或闭环、混沌或周期），上述界都成立。∎
*注.* 这把 Phase 0 发现的“闭环正反馈锁死”问题从“稳定性”问题降为“音乐性”问题：系统不可能发散，剩下的是映射设计。

## 3. 可激介质控制层（Barkley 1991）

**选择与理由.** 在 Barkley、FitzHugh–Nagumo、Aliev–Panfilov 三者中选 **Barkley 模型**（D. Barkley, *Physica D* 49 (1991) 61–70, doi 10.1016/0167-2789(91)90194-E，已核实）：
1. 专为“快速计算机模拟可激介质波”设计，两变量、只有 u 扩散，代价最低；
2. 参数 (a, b, ε) 直接控制激发阈值 b/a 与恢复速度，易于映射为音乐参数（“激发度”“速率”）；
3. 稳定螺旋波与靶波是其标准行为，且粗网格下仍保持定性正确（原文即强调这一点）——正好对应我们在 8×8 小晶格、控制率上运行；
4. 不变区：精确 ODE 下 u ∈ [0,1]，便于有界映射（我们实测显式步长 dt ≤ 0.016 时 u 保持在 [0,1]）。
FitzHugh–Nagumo 需要更细的时间步才能稳定显示螺旋，Aliev–Panfilov 面向心肌动作电位形状，额外参数对音频控制没有收益。

**离散化.** 在蜂窝格点图上：du_i/dt = u_i(1−u_i)(u_i − (v_i+b)/a)/ε + D Σ_{j∼i}(u_j − u_i)，dv_i/dt = u_i − v_i；显式 Euler，参数 a=0.75，b=0.03，ε=0.02，D=0.5。控制节拍 750 Hz（每 64 样本），每节拍 S 个子步，dt = 0.016；模型时间单位 τ = (1/12 s)/S。

**拓扑电荷.** 相位 θ_i = atan2(v_i − 0.25, u_i − 0.45)，对每个六边形 plaquette 求绕数，螺旋核心为 ±1。

**实测（p1_d_excitable.json）：**
- 8×8（128 格点）：20 组随机断裂波前中 95% 形成并维持螺旋 300 个时间单位（25 s @ τ=83 ms）；12×12、16×16、24×24、32×32：100%；
- 螺旋周期 5.712 模型单位（= 0.476 s @ τ=83 ms），与细步长 dt=0.002 参考相比偏差 +2.0%；
- 步长鲁棒性：dt = 0.004…0.048 均保持单个螺旋，dt=0.032 起 u 轻微越界（min −0.038、max 1.012），dt=0.064 失真（周期 4.67、u 最大 1.59）⇒ 采用 dt ≤ 0.016 + 子步；
- 靶波起搏（16×16 中心起搏）：起搏周期 ≥ 5 单位时 1:1 传到远角，3–4 单位时 2:1，2 单位时 3:1（不应期分频），单脉冲传播时间与速度见 JSON；
- 音频驱动触发（8 s 合成鼓组，低频包络→“踢”端口、高频包络→“军鼓”端口，滞回阈值）：24/24 个真实起音被检出，检测延迟中位数 1.33 ms（=1 个控制块），另有 5 个多余触发（踢鼓尾音）；用反事实对照（有/无该刺激各跑 2 个单位）判定“真正发出新波”的比例：τ = 83 / 42 / 21 ms 时为 72% / 69% / 97%——失败的触发落在前一个波的不应期内，这是可激介质的固有“节律分频”行为，可作为音乐特征（速率旋钮）。

**到声学层的映射（ParamMap）.** g_i = g₀(1 − 2κ_g u_i)（κ_g = 1 时被激发处回旋反号 ⇒ 局部 Chern 数反号，螺旋波拖动拓扑畴壁运动），μ_i = min(μ₀ + κ_μ u_i, μ_max)，α_i = α₀(1 + κ_α u_i)。所有输出都在 𝒜 内，命题 6 适用。

## 4. 拓扑：音频参数下的能带与边缘输运（p1_b_topology.json）

参数：f_unit = 1500 Hz（ω_u = √(k_c/m)），k₀ = 0.1k_c，g = 0.6ω_u，m=1，f_s = 48 kHz。
- 体能带（Hz）：[204–448]、[1104–1500]、[2229–2400]、[2794–3129]，Chern 数 [1, 0, 0, −1]（FHS 格点法）；
- 带隙：448–1104 Hz（656 Hz 宽）、1500–2229 Hz（729 Hz）、2400–2794 Hz（394 Hz），每个带隙下方 ΣC = 1 ⇒ 每条边一支手性边缘态；
- 时域（40×14 薄片，6000 步，4 ms 高斯脉冲，带吸收边框）：Ω+ 时带隙 1（776 Hz）右/左能量比 +52.1 dB，带隙 2（1865 Hz）+55.1 dB；在边缘挖出缺口后仍为 +51.9 / +54.0 dB，相对干净情形的透射变化 −0.0 / +0.0 dB（缺陷绕行，无背散射）；Ω− 方向反转（−58.0 / −57.9 dB）；Ω = 0 无方向性（−5.0 / −1.7 dB）；体带频率（1302 Hz）无保护（−3.2 dB，缺陷处透射 −3.9 dB）。

## 5. CFL 与可容许参数

γ = h·ω_max/2：音频参数、m=1 时 ω_max = 2π·3129 Hz ⇒ γ = 0.205；m_min = 0.5 ⇒ γ = 0.290。C++ 中使用保守界 λ_max(K) ≤ k₀ + 2k_c·d_max（因 n nᵀ ⪯ I，弹簧部分 ⪯ k_c L_graph ⊗ I，λ_max(L_graph) ≤ 2d_max），给出 γ = 0.242（m=1）。
