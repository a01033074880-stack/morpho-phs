# MORPHO-PHS Phase 6a 美术方向（Art Direction）

> 状态：已实现（JUCE 8，AGPLv3）。本文件是视觉语言的唯一规范；代码中的数值以 `plugin/Source/ui/Theme.{h,cpp}`、`plugin/Source/ui/BrandGeometry.h`（由 `scripts/brand/gen_brand.py` 生成）为准。
> 调研笔记见 `docs/phase6/art_research.md`（参考：Vital、Surge XT、Cardinal、Dexed、ChowDSP、Odin 2、Airwindows Consolidated 等开源插件）。我们**没有套用**任何现成的皮肤或 LookAndFeel 模板，所有图形都是从本项目的物理模型推出来的。

## 1. 概念：「体暗边明」(BULK · EDGE)

MORPHO-PHS 的物理核心是一张端口哈密顿（port-Hamiltonian）陀螺蜂窝晶格：手性打开带隙后，**体（bulk）是绝缘的**，能量只能沿**拓扑边缘通道**单向绕行；Barkley 可激介质在其上生长缺陷，重塑多面体。视觉语言直接翻译这三件事：

| 物理事实 | 视觉规则 |
|---|---|
| 体在带隙内是绝缘的 | 背景与面板是**哑光深色**（bulk0/1/2），没有渐变、没有发光、没有模糊 |
| 边缘通道导通 | 只有“活跃的边”才使用强调色（accent）：选中按钮的六角边框、宏旋钮弧、边缘通道描边与箭头 |
| 只有能量会“发光” | 唯一的亮度来源是能量热度色阶（heat ramp，log 能量，40 dB 窗口） |
| Barkley 介质是另一种场 | 介质 u 用 **60° 斜线排线（hatching）** 表示，而不是第二种颜色 |
| 手性 = 方向 | 手性符号决定边缘箭头（chevron）的绕行方向；手性≈0 时箭头消失 |
| 蜂窝几何 | 所有角度是 60° 的倍数：六角胶囊按钮、六角刻点、旋钮指针带 ±120° 的两根“尾键”（就像一个三配位格点） |
| 陀螺 | 旋钮指针 = 一个陀螺格点的位移；Hero 中的“针”是每个格点的实时位移方向 |

一句话：**界面本身就是一块处在带隙中的材料——暗的体、亮的边、只有能量会发光。**

唯一的“主角”（hero）是中央的晶格可视化；其余控件都退后一层。

## 2. 色板（tokens）

| Token | 值 | 用途 |
|---|---|---|
| bulk0 | `#0B0D12` | 最底层背景、Hero 底 |
| bulk1 | `#11141B` | 面板 |
| bulk2 | `#181C25` | 凹槽（旋钮井、推子轨） |
| seam | `#262B37` | 发丝线（1 px 分隔、面板边框、键位） |
| seamHi | `#363D4D` | 悬停时的发丝线 |
| ink | `#E9E6DF` | 主文字、数值（暖白，不是纯白） |
| inkDim | `#9AA1B2` | 标签、次要文字 |
| inkFaint | `#6B7385` | **仅装饰**（刻度端点），不承载信息 |
| accent（乐器） | `#59D8F0` | 冰青：陀螺 / 冷的边缘通道 |
| accent（FX） | `#C8F05A` | 酸性黄绿：处理器 / “信号在边上被改写” |
| accentDim | accent × 22% | 选中按钮的填充 |
| warn | `#F07A3A` | = 热度色阶 H3。CPU 警告**复用能量色阶**，不引入新色相 |
| heat H0…H4 | `#141826 → #3B2363 → #A3305A → #F07A3A → #FFE7A8` | 能量色阶（256 项 LUT），从“冷的体”到“白热” |

规则：一个界面只用一种强调色；强调色只出现在“正在导通”的地方。

### 2.1 WCAG 对比度（实测，相对亮度公式）

| 前景 | 对 bulk0 | 对 bulk1 | 对 bulk2 | 结论 |
|---|---|---|---|---|
| ink | 15.59 | 14.78 | 13.68 | AAA |
| inkDim | 7.51 | 7.12 | 6.59 | AAA（≥7）/ AA |
| inkFaint | 4.09 | 3.87 | 3.59 | 不达 4.5 → 只用于装饰 |
| accent 乐器 | 11.57 | 10.97 | 10.15 | AAA |
| accent FX | 14.87 | 14.10 | 13.05 | AAA |
| warn (H3) | 6.99 | 6.62 | 6.13 | AA |
| heat H2 | 2.89 | 2.74 | 2.54 | 仅用于场图，不写字 |
| seamHi | 1.79 | 1.69 | 1.57 | 仅线条 |

反向：bulk0 文字在 accent 乐器上 11.57，在 accent FX 上 14.87（选中态反白文字安全）。键盘白键 `#9AA3AE` 上的 C 标签（bulk0 × 85%）为 6.11。
未分配的宏旋钮：表盘整体降到 42% 不透明度（≈3.4:1，属于“非文字图形”，WCAG 1.4.11 要求 3:1），标签保持 inkDim（7.1:1），数值换成“—”，因此不会出现低对比度文字。

## 3. 字体（SIL OFL 1.1）

- **IBM Plex Sans Condensed** Medium / SemiBold：标签、按钮、标题。窄体在 8 px 网格里能放下全大写标签。
- **IBM Plex Mono** Regular / Medium：全部数值读数、信息行、状态行——数值等宽，拖动时不抖动。
- 文件在 `plugin/Assets/fonts/`，许可证 `plugin/Assets/fonts/IBMPlex-OFL.txt`，以 BinaryData（`UiAssets` 命名空间）未修改地嵌入。"Plex" 是保留字体名，我们没有改名或修改字体。
- 标签一律全大写并加字距（tracking 0.07–0.14 em）；数值不加字距。

## 4. 网格、尺寸与缩放

- 设计画布 **1152 × 720**，8 px 网格（`kGrid = 8`），面板内边距 12/16。
- 可缩放范围 960×600 … 1728×1080（0.83× … 1.5×），**固定长宽比 1.6**。
- 实现：编辑器只持有一个 `MainPanel` 子组件，按 `AffineTransform::scale(w/1152)` 变换；**从不调用 `setScaleFactor`**。JUCE 会以物理像素重新光栅化矢量，因此 HiDPI（2x）下文字和线条是清晰的。
- Hero 的逐像素层按**物理像素**生成（上限 2.6 Mpx），矢量覆盖层（边缘、端口、缺陷、文字）始终是全分辨率矢量。
- 窗口宽度保存在插件状态（`MorphoExtra@ui_width`），重新打开时恢复。

布局（设计坐标）：顶栏 0–56（字标、预设栏、CPU 芯片、ECO、ABOUT）；工具行 y 64；Hero (16,100,696,388)；右栏：宏 4×2、配置（激励器/模式 + 晶格尺寸）、混音；下栏：物理 6 旋钮 + 监视器；底行：乐器 = 键盘，FX = 4 个横向推子；状态栏 y 696。高级抽屉覆盖下栏（16,504,1120,184）。

## 5. 控件与图标

- **旋钮**：弧形轨道 + 端点刻度；数值弧（宏 = accent，其他 = ink）；bulk2 凹井；指针 = 陀螺格点（主键 + ±120° 两根尾键）；弧端的六角“格点”就是值的位置；下方为大写标签 + 等宽读数。双极参数（手性）从 12 点方向向两侧填充。
- **交互**：相对拖动（(dx−dy)/220，Shift 精细 /1100），无界鼠标移动；双击或 Alt/Cmd 单击复位到默认；滚轮 0.1 步（Shift 0.02）；方向键 0.01（Shift 0.002）；Home/Delete 复位；拖动时读数变为 accent。所有旋钮提供无障碍 slider 接口。
- **按钮**：六角胶囊（两端 60° 尖角），相邻按钮共享尖角形成“分段条”；选中 = accent 边 + accentDim 填充。
- **图标**：12 个，全部用代码以 60° 几何画出（Pluck、Morph、Chisel、Erase、Spiral、Clear、Reset、Info、Eco、Prev、Next、Drawer），1.5 px 描边，无位图。
- **推子（FX 底行）**：标签 | 六角胶囊轨 | 等宽读数。

## 6. 动效规则（性能即美学）

- 只有 Hero 和监视器会动。其余控件只在参数变化时重绘。
- Hero 帧率：活跃 30 fps；ECO 12 fps；连续 45 帧“低运动”后降到 8 fps；窗口隐藏 / 最小化 / 编辑器关闭时为 0（音频线程停止发布快照）。
- 高级抽屉 160 ms 滑出（ECO 下瞬时）；没有弹簧、没有模糊、没有阴影动画、没有粒子。
- 静态层（顶栏、面板、字标、网格）缓存为图像（`setBufferedToImage`），每帧只合成。

## 7. 品牌：字标、标志、图标

- **标志（glyph）**：一个六边形晶胞，中心是三配位格点（三根键 + 节点），右上角的边被一段 accent 弧取代并带箭头——“沿边缘绕行的能量”。边描边 0.13 r，键 0.12 r，节点半径 0.17 r。
- **字标**：`MORPHO-PHS` 由代码绘制的单线条大写字母（kStroke 1.5 @ cap 10，按 cap 高缩放），FX 版本追加 accent 色的 “FX”。
- 生成器 `scripts/brand/gen_brand.py` 同时输出 SVG（`plugin/Assets/brand/`）、插件图标 PNG（512/256，`ICON_BIG/ICON_SMALL`）和 C++ 几何头文件 `BrandGeometry.h`，保证图标、关于页与界面中的标志完全一致。
- **About / 致谢面板**：点击 ABOUT 打开，卡片包含标志、字标、版本号、乐器说明、致谢与许可证（AGPLv3、JUCE 8 AGPLv3 选项、clap-juce-extensions MIT、IBM Plex OFL 1.1）。点击任意处或 Esc 关闭。

## 8. 乐器 vs FX 的身份

| | 乐器 MORPHO-PHS | FX MORPHO-PHS FX |
|---|---|---|
| 副标题 | GYROSCOPIC LATTICE SYNTH | TOPOLOGICAL EDGE FX |
| 强调色 | 冰青 `#59D8F0` | 酸性黄绿 `#C8F05A` |
| 配置行 | 激励器（Bow / Pluck）+ 晶格尺寸 | 模式（Edge Disperser / Defect Freezer）+ 晶格尺寸 |
| 底行 | MPE 键盘（36–96） | 4 个推子：Edge width / X-talk / Spread / Defect |
| 物理行第 5 个旋钮 | Life（门控自激） | Freeze |
| 图标 | glyph_inst | glyph_fx（同一几何，FX 色） |

两者共用同一套几何、字体与布局；只靠强调色和底行区分，用户一眼可知是哪一个。

## 9. Hero：晶格可视化

- 每个格点按 log 能量（40 dB 窗口，自动量程，慢释放）取热度色；按位移 q 做“面倾斜”明暗（光从左上来）——这就是“变形多面体”。
- 体内暗色的六角孔是蜂窝的空心；键是发丝线；缺陷格点变暗并画白色六角环。
- 介质 u 以 60° 排线叠加（H+u 层 150/255，u 层 235/255）。
- 边缘通道：outline + 手性箭头（边缘模式更亮）+ 沿边缘键的能量短划（4 档透明度）。
- 端口：SRC = accent 六角 + 标签；L/R 拾音 = ink 圆环；画笔 = 虚线环；乐器声部 = 实心 accent 六角。覆盖层都有一道 bulk0 暗衬线，在饱和（白热）场上依然可读。
- 信息行：L、格点数、线程数、H（大数用科学计数法）、复位次数；能量门（E_cap）生效时显示中性的 “E-GATE REGULATING”——这是弓 / Life 增益的设计内限幅器，不是故障，所以不用警告色。
- 三个图层按钮：H+u / H / u。

## 10. CPU 指示

CPU 芯片显示 `AUTO nT`（自动线程）、`HIGH …`（高 CPU 设置，如 32×32 + HQ 精确）、`HQ>FAST …`（HQ 精确被降级为快速近似）。警告使用 warn（= 热度 H3）。同样的信息出现在高级抽屉的说明框、POTENTIAL / THREADS 标题与工具提示、以及状态栏末尾。

## 11. 性能契约

1. 音频线程只向 TripleBuffer 发布**抽取后的快照**（无分配、无锁）；`snapshot_hz = 0` 时不发布。
2. 发布开销：快照 30 Hz 时 < 1% 预算（实测见 Phase 6a 报告）。
3. UI ≤ 30 fps；ECO 12 fps；低运动 8 fps；隐藏 / 关闭 = 0 Hz 发布。
4. 不用模糊、不用阴影、不用逐帧渐变；静态层缓存。
5. Hero 每帧只做一次逐像素合成（站点图、键掩码、排线都在几何变化时预计算）。
6. 每次修改都用快照工具（`morpho_ui_snap_{inst,fx}`）在 1x / 2x 下测 paint 时间。
